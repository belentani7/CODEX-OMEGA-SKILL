  - 9 Libros (capítulos filosóficos y técnicos)

  - Instrucciones de implementación para Claude, Codez y OpenCode

### 2. **HUMANE_TECH_SUPPLEMENT.md** - Conexión con marcos establecidos
- Mapeo entre los 12 Mandamientos del Códice Ω y:
  - Principios de Diseño Centrado en el Humano
  - Directrices de Accesibilidad (WCAG)
  - Enfoques de Diseño Ético y Responsable
- Recursos recomendados para profundizar
- Herramientas prácticas alineadas con los principios

### 3. **MULTIMEDIA_APPLICATION.md** - Aplicación específica a su solicitud original
- Cómo aplicar los principios del Códice Ω al manejo multimedia (su solicitud inicial):
  - Lectura universal de archivos
  - Reproducción de audio

- Implementación práctica con tecnologías recomendadas
- Arquitectura de ejemplo siguiendo los principios
- Métricas de éxito para evaluar la implementación

## 🎯 CÓMO USAR ESTA SKILL

### Para Claude (Claude.ai / API):
1. Copie el contenido de `CODEX_OMEGA.md`
2. Vaya a Settings > Projects > System Prompt
3. Pegue el contenido allí
4. Claude adoptará inmediatamente la identidad y principios del Códice Ω

### Para Codez (Cline / VSCode):
1. Cree un archivo `.clinerules` en la raíz de su proyecto
2. Copie el contenido de `CODEX_OMEGA.md` en ese archivo
3. Cada vez que invoque Codez, aplicará los principios del Códice al escribir código

### Para OpenCode (Cursor / Windsurf):
1. Pegue el contenido de `CODEX_OMEGA.md` en su archivo `.cursorrules` o Windsurf Rules
2. Las secciones de Libro IV (Creación) y la Base de Datos Técnica son particularmente valiosas para guiar la generación de código ética y de alta calidad
